# Minnieverse local soundtrack

The site plays MP3 files from this folder with its native in-page audio player. Track buttons do not link to YouTube or any external streaming page.

Add only audio files you have permission/licences to host on this public repository:

- `doraemon.mp3` — Doraemon songs / OSTs
- `tame-impala.mp3` — a Tame Impala track
- `maneskin-beggin.mp3` — Måneskin, “Beggin’”
- `maneskin-i-wanna-be-your-slave.mp3` — Måneskin, “I Wanna Be Your Slave”

Until a file is added, tapping its track displays a clear missing-file message. GitHub Pages is static hosting; no backend or external service is needed. MP3 files added to a public repository can be downloaded by visitors, so only host copies you are authorised to redistribute.
